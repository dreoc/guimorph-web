<objective>
Extend the Phase-4 server-owned-state pattern from "one landmark matrix per token"
(`.gmw_picks`) to a full per-specimen digitizing record (`.gmw_session`), and add the
token-guarded loopback routes the browser uses to edit it: anchor, curve-by-index,
delete, undo, and specimen-switch — plus thin forward-call branches for the analytical
routes (downsample, gpa, export, save) whose seams land in plans 05-04/05/06. This is
the transport surface for all of Phase 5; it is edited once, in Wave 1, so the Wave-2
plans (view3d.R, surface.r, geomorph.r, main.r) never touch transport.R.

Purpose: R owns all digitizing state independently of the C engine (`tkogl2`), which
Phase 6 deletes (RESEARCH Anti-Patterns / Assumption A3). Curves are indices, not
coordinates (RESEARCH Pitfall 5); curves are session-scoped, shared across specimens
(`activeDataList[[1]][[4]]`, Assumption A7).
Output: `.gmw_session` model, accessor, undo grammar, and the digitizing route surface.

PLANNER DECISION (A5, recommended default, user may override): route shape is
per-route `httpuv::excludeStaticPath()` entries + a single `call` handler with `grepl`
branches (matches the Phase-4 `/pick` precedent; simpler handlers), NOT one `/edit`
verb-in-body route. Both preserve the no-path-join invariant.

PLANNER DECISION (A4, recommended default, user may override): multi-specimen switch is
delivered by RE-SERVE — the `/specimen` route sets the current index, clears undo, and
returns the target specimen's mesh URL + flattened overlays; the browser loads that mesh
and rebuilds the BVH (one mesh live at a time, matches D-01). NOT serve-all-and-toggle.
</objective>
