<objective>
Complete WEB-04's runtime half on top of plan 01's teardown machinery: (1)
convert the httpuv app from static-only to a mixed app with one dynamic
`/<token>/close` route that fires plan 01's `.gmw_stop_token(token)` (the D-02
browser tab-close trigger, server side); (2) surface the already-coded
walk-forward port backup as a user `port` argument with a clear exhaustion error
(D-08/D-09); (3) harden the browser-launch path to degrade legibly (D-05/D-06/D-07).

Purpose: These are the three managed-machine failure modes that each present to a
lab user as "the software is broken" — an unclosable viewport, an occupied port
that hangs, and a locked-down default browser.
Output: an extended `.gmw_serve_mesh()` (mixed app + `port` arg + launch
messaging), a sharpened `.gmw_pick_port()` exhaustion message, and the
direct-closure / port-exhaustion / launch-messaging test blocks.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/other local process → `/close` route (R `call` handler) | Untrusted request path crosses into R; must be pattern-matched only, never joined to the filesystem |
| R process → OS network stack (port bind) | Occupied ports must fail loudly, never hang |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-01 | Tampering / Info Disclosure | `/close` `call` handler | high | mitigate | Handler only `grepl("/close$", ...)` and calls `.gmw_stop_token(token)`; never `file.path`/`normalizePath`/`readBin` from the request path (asserted in Task 1). Static byte mount untouched (T-2-02) |
| T-3-02 | Denial of Service | `/close` route hit by a local process | low | accept | Route stops only that token's own viewport — a capability the owning tab already has; loopback-only + token-scoped bounds blast radius to one already-owned viewport |
| T-3-05 | Info Disclosure | LAN exposure of specimen | high | mitigate | `host = "127.0.0.1"` only; the plan-01 guard test asserts `0.0.0.0` absent — unchanged here |
| T-3-06 | Denial of Service (resource) | occupied preferred port hangs the launch | medium | mitigate | Walk-forward backup + D-09 exhaustion `stop(call.=FALSE)` naming the range; unit test proves an error not a hang |
| T-3-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages installed this phase (RESEARCH audit: none). `later` is a pre-existing transitive dependency |
</threat_model>
