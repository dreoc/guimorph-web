<objective>
Build the R-side teardown machinery for the viewport server so a closed listener
can never orphan (WEB-04). Adds a single registry-driven stop helper wired to
three of the four D-01 triggers (explicit `gmw_close()`, R session end via
`reg.finalizer(onexit=TRUE)`, namespace unload via `.onUnload()`); the fourth
trigger (browser tab-close `/close` route) lands in plan 02 and reuses this same
helper. Also re-scopes the stale Phase-2 `PATH_INFO` source-guard test now, so
plan 02 can add a `/close` handler that reads `req$PATH_INFO` without tripping a
healthy change against a stale assertion (RESEARCH Pitfall 3).

Purpose: A never-orphan teardown is the load-bearing half of WEB-04 on managed
lab machines; getting the R lifecycle hooks exactly right is the concentrated
risk of this phase.
Output: `.gmw_lifecycle` env, `.gmw_stop_token()`, exported `gmw_close()`,
`.onUnload()`, a lazily-registered session-end finalizer, a regenerated
`NAMESPACE`, and the teardown + re-scoped-guard + CMP-01 test blocks.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| R process → OS sockets | Teardown must release every bound loopback port it owns; a leaked listener holds a port after the viewport is gone |
| GUImorphWeb → other in-process httpuv servers | A user may run shiny/plumber in the same R session; teardown must not touch their listeners |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-03 | Denial of Service | `.gmw_stop_token()` teardown | high | mitigate | Iterate `.gmw_server` and stop only owned handles; `httpuv::stopAllServers()` is forbidden (asserted absent in Task 1 verify) |
| T-3-04 | Denial of Service (resource) | orphaned listener after partial teardown | high | mitigate | `.gmw_stop_token()` always does BOTH `stopServer()` and `rm()`; `reg.finalizer(onexit=TRUE)` backstops session end; test asserts `listServers()` empty after stop-all |
| T-3-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages installed this phase (RESEARCH Package Legitimacy Audit: none). `httpuv`/`later` already present; no install task exists |
