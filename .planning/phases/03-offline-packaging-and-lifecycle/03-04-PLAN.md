    Create a NEW file `tests/testthat/test-offline-smoke.R` (filter name `offline`).
    It must skip cleanly rather than fail when the tooling is unavailable — guard
    at the top with `skip_if_no_pkg_source()`, `skip_if_no_curl()`, and
    `skip_if_not_installed("pkgbuild")` (and skip if `R CMD build`/pkgbuild cannot
    run in the sandbox). The test is deliberately marked as the slow integration
    check (RESEARCH Open Question 2 — a runnable script a human triggers per
    platform; no CI exists).

    In one `test_that("a fully-offline source install ships the bundle and serves it", ...)`
    (RESEARCH §Code Examples, Pitfall 6):
    1. Build the tarball from `pkg_source_root()` with `pkgbuild::build(..., dest_path = tempdir())`
       (or `R CMD build`).
    2. Create a throwaway lib dir with `tempfile()` + `dir.create()`.
    3. Install OFFLINE: `install.packages(tarball, repos = NULL, type = "source", dependencies = FALSE, lib = <templib>)`.
       The `repos = NULL` + `dependencies = FALSE` pair is load-bearing — it is
       what makes the install offline (Pitfall 6: `dependencies = TRUE` silently
       reaches CRAN and the test no longer proves anything). Assumption A4: the
       host already has the Imports (geomorph/Rvcg/tcltk/tcltk2/httpuv) present.
    4. Under `withr::with_libpaths(<templib>, { ... })` assert
       `nzchar(system.file("htmlwidgets", "guimorphweb-three.js", package = "GUImorphWeb"))`
       (the WEB-00 bundle ships inside the installed package).
    5. Serve the committed fixture via the installed package's
       `GUImorphWeb:::.gmw_serve_mesh(fixture, open = FALSE)` and, using
       `gmw_try_fetch`, GET `<url>specimen.ply`: assert status `200L` and that the
       returned bytes are `identical()` to the on-disk fixture bytes
       (`readBin`), i.e. served raw, never JSON.
    6. GET the page (`<url>`) and assert it contains NO external reference: the
       page text must not match `src="https?://` nor `href="https?://` (offline by
       construction; the plan-03 beacon uses a relative target so it does not trip
       this).
    7. Always tear the served listener down (`gmw_close()` or the installed
       `stopServer` + `on.exit`) so no listener leaks, and remove the temp lib.

    Use the same committed ~0.77 MB fixture the transport suite uses
    (`tests/fixtures/parity/B12_1_clean.ply`); the ~30 MB worst case stays in the
    manual UAT (Task 2). Do not add a network call anywhere in the test.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installed package → network during "offline" install | The smoke test must not reach the network; `dependencies=TRUE` would silently fetch from CRAN |
| served page → external asset origins | Any external `src=`/`href=` would break offline-by-construction and leak a runtime fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-07 | Information Disclosure | external page reference / runtime fetch | high | mitigate | Test asserts the served page has no `src="http(s)://"`/`href="http(s)://"`; install uses `repos=NULL, dependencies=FALSE` so nothing is fetched (Pitfall 6) |
| T-3-08 | Spoofing / Tampering | a non-offline install masquerading as the offline proof | medium | mitigate | `repos=NULL` + `dependencies=FALSE` asserted in source; test makes no network call; runs with network physically off in the manual UAT |
| T-3-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages installed. `pkgbuild`/`withr` are dev-time Suggests-guarded (`skip_if_not_installed`), not runtime deps; bundle was vendored in Phase 1 (WEB-00) |
</threat_model>
