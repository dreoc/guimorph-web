<objective>
Add the page (browser) half of the D-02 tab-close teardown: fire
`navigator.sendBeacon("close")` from the viewport page when it goes away, so
closing the tab reaches plan 02's `/<token>/close` route and stops that token's
server. This is the best-effort trigger of the four D-01 triggers — the plan-01
finalizer and `gmw_close()` remain the guarantees, so a missed beacon never
orphans past session end.

Purpose: A user who just closes the browser tab expects the viewport gone; this
closes that path without a polling heartbeat (D-02, fewer moving parts).
Output: the `pagehide` + `visibilitychange` `sendBeacon` hook in
`GMW_VIEW3D_TEMPLATE`, plus a source-scan test asserting the reliable event is
used and no external reference is introduced.
</objective>

    `window.addEventListener("resize", resize)` / `"keydown"` block (RESEARCH

    `gmwClose` function that calls `navigator.sendBeacon("close")` inside a
    `try/catch` (swallow any error), then register it on `window`'s `pagehide`
    event AND on `document`'s `visibilitychange` event firing only when
    `document.visibilityState === "hidden"` (the backstop). Use `pagehide`, NOT
    the deprecated/unreliable `unload` event (Pitfall 4).

    The beacon target is the RELATIVE string `"close"` — it resolves against the
    page URL `http://127.0.0.1:PORT/<token>/` to `.../<token>/close`, i.e.
    same-origin, same token, with no absolute URL and no server-side path parsing.
    Do NOT hardcode a host, port, token, or any `http(s)://` absolute URL — that
    would both break for other tokens and introduce an external reference
    (WEB-03 offline-by-construction). This adds no `src=`/`href=` reference of any
    kind.

    Because the template is a `sprintf` string, any literal `%` you write must be
    escaped as `%%` (mirror the existing `100%%` / `"%%"` usages already in the
    file). The beacon snippet as written contains no `%`, but keep this in mind if
    you adjust surrounding text.
  </action>
