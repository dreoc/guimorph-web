<objective>
Extend `GMW_VIEW3D_TEMPLATE` in `view3d.R` with the browser half of picking: (1) an eager
BVH build plus a pointer→raycast handler that reports the mesh-local hit to R over the
relative `/pick` route (PICK-01 browser side); (2) an overlay `THREE.Group` that draws a
landmark dot at the hit with correct depth under rotation (PICK-02); and (3) a
record-and-replay entry point that reproduces a recorded native ray by copying the captured
matrices onto a camera and raycasting the recorded pixel against the mesh at identity — the
browser half of the PICK-03 parity harness (PICK-03).

Purpose: raycasting is resolution-independent, so the browser can return a hit that is
directly comparable to the native `gluUnProject` object coordinate with no backing-scale
correction (criterion 4). The replay path is built now against the schema-true placeholder
fixture so the real Windows capture drops in with zero code change (D-05/D-07).

Output: extended `R/view3d.R` template and a new `test-picking-view3d.R` source-scan.
</objective>
