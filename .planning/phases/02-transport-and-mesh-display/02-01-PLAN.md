<objective>
Add a mesh-from-URL rendering branch to the Phase 1 three.js template so the browser
can fetch a served PLY and render it as a solid shaded surface with orbit, zoom, and
reset — the WEB-02 render half of the phase. This plan changes only the browser page
generator (`R/view3d.R`); the httpuv transport that serves the page and mesh is plan
02-02, which consumes the `.gmw_view3d_html()` builder produced here.

The change parametrizes the existing `GMW_VIEW3D_TEMPLATE` (CONTEXT "Claude's
Discretion" prefers reuse over a fork) rather than duplicating it, honouring D-03
(solid `MeshLambertMaterial`, not wireframe/points) and D-04 (`#cccccc` on `#ffffff`,
`side: THREE.DoubleSide`). The point-cloud path used by PLT-01 must keep working.

Purpose: WEB-02 render logic (PLYLoader + deferred framing + orbit/zoom/reset).
Output: a modified `view3d.R` exposing `.gmw_view3d_html(clouds, mesh, mesh_url, title, background)` and a mesh-URL branch in the template, plus a source-level render test.
</objective>
