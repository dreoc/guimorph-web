<objective>
Build the WEB-01 transport: a loopback `httpuv` server started from R that serves one
specimen PLY (D-01, single path, one guarded endpoint) as raw bytes behind a
per-session random path token, plus the delivery wiring that opens the browser on the
served page produced by plan 02-01. Adds `httpuv` to the package (currently absent from
Imports and `renv.lock`) and proves the server is byte-faithful, loopback-bound, and
guarded, while confirming the native `tkogl2` oracle still loads (CMP-01).

No in-page specimen picker (D-02 — multi-specimen switching stays Phase 5). Robust
teardown, port-collision recovery, and browser-launch degradation are Phase 3 (WEB-04)
and are explicitly out of scope; this plan only needs the listener to stay alive for the
session (retain the handle against GC).

Purpose: WEB-01 (transport + guard) and the WEB-02 server-side delivery; CMP-01 gate.
Output: `R/transport.R`, `httpuv` in DESCRIPTION/renv.lock, and a transport test suite.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other local process → httpuv listener | Any process on the same host can attempt to connect to the loopback port and enumerate paths to read specimen files. |
| HTTP request path → filesystem | A crafted request path could attempt directory traversal to read files outside the served tempdir. |
| host interface selection | Binding the wrong interface would expose the specimen to the LAN. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-01 | Information Disclosure | loopback listener + endpoint enumeration | high | mitigate | Bind `127.0.0.1` only + per-session >=128-bit random path token (`.gmw_token`); short-lived per-session server. Guard verified by the token-guard test (Task 3). |
| T-2-02 | Tampering / Information Disclosure | request path → filesystem (path traversal) | high | mitigate | Serve via `httpuv::staticPaths`/`staticPath` (safe path resolution within the mounted tempdir); never build a file path from `PATH_INFO` in a `call` handler. Asserted by source-scan (Task 2/3). |
| T-2-03 | Information Disclosure | server bind interface | high | mitigate | Explicit `host = "127.0.0.1"`, never `0.0.0.0`. Asserted by source-scan (no `0.0.0.0`). |
| T-2-04 | Spoofing | guard token RNG strength | medium | mitigate | >=128-bit token; base-R generator with documented residual risk (RESEARCH A1); loopback + temp-dir filesystem perms are defence-in-depth. Cryptographic RNG deferred (would add a dependency + decision checkpoint). |
| T-2-05 | Denial of Service | orphaned listener / port leak | low | accept | Retain handle in `.gmw_server` (prevents accidental GC stop). Robust teardown on viewport close / session exit / R end is WEB-04 / Phase 3 — deliberately out of scope here; residual risk is a leaked session listener, accepted for Phase 2. |
| T-2-SC | Tampering | dependency install (`httpuv` from CRAN) | low | mitigate | No npm/PyPI/crates installs this phase (browser bundle vendored + committed in Phase 1). `httpuv` is CRAN, Posit-maintained, ~10+ yr history, the transport under `shiny` — RESEARCH Package Legitimacy Audit verdict OK, no `[ASSUMED]`/`[SUS]`/`[SLOP]`; no blocking human checkpoint required. |
</threat_model>
