<objective>
Grow the existing mixed `httpuv` app in `transport.R` with the shell-support routes the
new browser chrome needs — the D-03 file picker (`/files` list, `/open` selection),
plus `/savepath`, `/status`, `/tabstate`, `/msgack`, `/color`. This is the server half
of UI-01: R keeps owning the filesystem, the browse directory, and every chosen path;
the browser only ever returns a selection from R's own enumerated set.

Purpose: The browser shell (Plan 02) and the Tk-dialog replacements (Plans 05/06) all
POST/GET these routes. Building them first gives the rest of the phase a stable contract.
Output: New dynamic suffixes + dispatch branches in `transport.R`, a `browse_dir` session
slot, and extended route/security tests in `test-transport.R`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `httpuv` (`/files`, `/open`) | Untrusted request body (a file selection) crosses into R filesystem access — the primary new attack surface of this phase |
| browser → `httpuv` (`/color`, `/savepath`, `/msgack`, `/status`, `/tabstate`) | Untrusted small bodies parsed by base R |
| listener → LAN | Loopback bind must not widen |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-6-01 | Information disclosure | `/files` directory listing | high | mitigate | Scope `list.files` to the server-owned `browse_dir`; filter to `\.(dgt|ply)$`; never recurse into parents or list absolute trees |
| T-6-02 | Tampering / Info-disclosure | `/open` path traversal | high | mitigate | R enumerates the dir; browser returns only a basename; open only if `sel %in% entries`; never `file.path(dir, untrusted)` with `..`/absolute (D-03, Pitfall 5) |
| T-6-03 | Denial of service | malformed `.dgt` on `/open` | medium | mitigate | Wrap the reader in `tryCatch`; surface a browser error (message body) instead of crashing the listener |
| T-6-04 | Information disclosure | LAN exposure of listener | high | mitigate | Keep `host = "127.0.0.1"` unchanged (inherited T-2-03); no wildcard bind added |
| T-6-05 | Tampering | injection via `/color` / other bodies | medium | mitigate | Bare CSV / hex-pattern validation, base-R parse only, no `eval`, no JSON (inherited T-4-02/T-5-04) |
</threat_model>
