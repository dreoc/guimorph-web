proceed safely.

anything is deleted. Output: `R/shell.R`, a trimmed `rtkogl.R`, and an entry/boot test.

`GUImorphWeb(dir = getwd(), open = TRUE, debug = FALSE)`, booting the browser shell via
`.gmw_serve_mesh(dir=, open=)` (print-first, auto-open convenience per REFERENCE-ARCHITECTURE).
